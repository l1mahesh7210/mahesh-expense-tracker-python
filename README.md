# Personal Expense Tracker

## Project Overview
A Python-based Personal Expense Tracker that helps users record, manage, analyze, and monitor their daily expenses.

## Features
- Add expenses
- View all expenses
- Search expenses
- Edit and delete expenses
- Calculate total spending
- Category-wise expense reports
- Monthly expense reports
- Budget alerts
- JSON file storage
- SQLite database storage

## Technologies Used
- Python
- SQLite
- JSON
- VS Code

## Project Purpose
This project was developed to practice Python programming, file handling, database integration, data management, and basic financial analysis.

## How to Run
1. Install Python.
2. Download or clone the project.
3. Open the project folder in VS Code.
4. Run:

```bash
python main.py
```

To run the SQLite version:

```bash
python sqlite_tracker.py
```
